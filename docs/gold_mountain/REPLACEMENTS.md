## Rules for placeholders

Temporary visual copy may be used during development, but do not publish false facts. The replacement ID should be referenced in code/data comments where practical.

When an item is replaced:
1. update this table
2. record the new asset/content source
3. re-run affected visual QA
4. update relevant page documentation
