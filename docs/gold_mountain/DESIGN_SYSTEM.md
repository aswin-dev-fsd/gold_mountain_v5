# DESIGN SYSTEM

## Brand foundations

### Brand essence

`Stay. Experience. Reconnect.`

### Brand line

`A peaceful resort experience in the presence of Arunachala.`

## Palette

| Token | Hex | Intended use |
|---|---|---|
| Warm Ivory | `#F7F3EA` | Main background, negative space |
| Forest Green | `#214D33` | Grounding colour, nav, major brand surfaces |
| Gold | `#C49A3A` | Premium accent, lines, selective headings/details |
| Deep Red | `#8F2D24` | Very restrained supporting accent |

### Colour behaviour

Do not use the four colours equally inside components. The 50/25/15/10 split applies to the overall visual language.

Default page background should usually be Warm Ivory. Use Forest Green for deep sections or navigation where it strengthens hierarchy. Use Gold sparingly. Use Deep Red rarely.

Avoid gradients unless there is a specific content/photo treatment that genuinely benefits from one; never add gradients merely because the brand contains Gold.

## Typography

### Primary: Outfit (Garet Alf)

Use for the structural system.

Suggested brand reference sizes from supplied identity guide:
- H1: 45px / 60px
- H2: 35px / 40px
- H3: 25px / 30px
- Body: 16px / 24px
- Accent: The Seasons italic/regular, 16px / 60px

These are starting reference values, not immutable screen measurements. Responsive type should scale appropriately while preserving the brand's spacious character.

### Secondary: The Seasons

Use selectively for:
- emotional statements
- descriptors
- supporting display text
- short quotes
- emphasis

Do not use the serif for long paragraphs.

## Layout

Preferred layout behaviours:
- wide editorial container
- strong left/right rhythm
- generous vertical whitespace
- full-bleed photography where appropriate
- split image/text compositions
- occasional asymmetric alignment
- fine dividers
- limited card use

Avoid uniform 3x3 card grids unless the content genuinely requires them.

## Buttons

Primary button should normally use Forest Green or another approved dark branded surface with strong contrast.

Gold may be used for a small highlight or selected CTA treatment, but should not turn every CTA into a gold pill.

Use consistent dimensions, focus states and hover behaviour.

## Borders and surfaces

Prefer fine lines and subtle separation over heavy shadows.

Cards should be used only when they improve information grouping.

## Decorative language

Allowed, sparingly:
- Arunachala line art
- mountain contour dividers
- crescent-inspired symbols
- minimal botanical line drawings
- thin signature accent lines

Decorative elements must reinforce the brand and must never compete with photography or content.

## Image treatment

Use natural, restrained image treatment.

Avoid over-saturation and heavy filters.

Cropping should preserve important subjects and avoid accidental distortion.

## Motion

Minimal motion only.

Use short, calm transitions and respect `prefers-reduced-motion`.

## Responsive rules

Desktop:
- spacious editorial layouts
- large photography
- split sections
- strong typography

Tablet:
- preserve hierarchy
- reduce gaps
- reorganize split layouts when needed

Mobile:
- recompose, do not merely shrink
- maintain readable typography
- retain generous breathing room
- stack content intelligently
- keep enquiry access obvious
